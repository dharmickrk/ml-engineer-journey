# ML Engineer Journey

A project-based path to becoming an ML engineer — learning by building increasingly difficult projects rather than working through courses in isolation. Each folder is a self-contained project with its own README covering the goal, approach, results, and what I learned.

## Projects

| # | Project | Concepts | Status |
|---|---|---|---|
| 01 | [Titanic Survival Prediction](./01-titanic) | Pandas, scikit-learn, classification, train/test splits, data leakage | ✅ Complete |
| 02 | House Price Regression | Regression, feature scaling, regularization | 🔜 In progress |

## Progression

Roughly following this path:
1. **Foundations** — classical ML with scikit-learn (classification, regression)
2. **Deep learning fundamentals** — neural nets from scratch, then PyTorch
3. **Applied deep learning** — computer vision, NLP, transfer learning
4. **Systems + deployment** — end-to-end projects, APIs, basic MLOps
5. **Specialization + research** — paper implementations, harder self-directed projects

Table above will grow as each project is finished.
